# 自动同步（0.7.4）

网页保持可见时每15秒读取当前正在查看的月份。龙虾写入打卡、项目、排序、月回顾标记或输出后，无须重开页面。仅数据或上海日期变化时重新绘制，不改变当前月份/视图及滚动位置。从后台返回、页面恢复、窗口重新获得焦点、网络恢复时立即尝试检查；关闭弹窗后约1.6秒再检查。暂停或操作期间跳过的检查会在下次安全机会执行，并不排队重复请求。

弹窗、输入框、正在触摸/键盘操作、本地保存、打卡及手动载入期间，不发起或不应用自动更新。并发检查只允许一个；响应返回时再次比较月份、手动读取序号和写入序号，旧响应直接忽略。写入保护与版本冲突处理继续由现有API执行。自动刷新只GET，不自动提交或覆盖任何备注。原输入和弹窗内容保持。

隐藏页面或浏览器判断离线时停止检查。请求10秒超时，失败仅提示同步暂时中断，下次安全检查自动重试；后台检查的401不会直接重载页面。后台定时器可能被系统暂停，返回前台后重新读取。网页/PWA必须联网；不会依赖Service Worker缓存个人记录。

网页会话API响应通过X-CSRF-Token带回当前令牌，前端更新元数据与退出表单令牌，适配记住设备恢复临时会话的情况。Bearer认证、JSON响应、既有接口均不变。跨过上海午夜时更新日期标记与未来日期限制，仍保留用户选择的月份与日期位置。

升级仅更新app.js、api.php、资源/缓存版本及文档，数据库无迁移，不改写用户记录。测试覆盖远端变化、无变化、弹窗/输入保护、过期响应、写入竞态、隐藏离线、错误恢复、跨天与滚动保留。
