## 开发环境复测

### 0.3.1 PHP 8.0 兼容验证

从 PHP 官方 Windows 归档获取 PHP 8.0.30 NTS，用其真实 HTTP 服务和 PDO SQLite 运行全部 115 项接口断言；PHP 8.4.26 同样通过。8.0.30 本地 SQLite 版本为 3.33.0。业务 PHP 文件全部通过 8.0 语法检查。覆盖登录/CSRF、计划/记录读写、备注及链接数组验证、历史候选、回顾锁定、用户隔离、迁移和备份；移除 never 与 array_is_list 依赖，无新增数据库迁移。测试中独立备份连接的计数转为数值比较，兼容 8.0 PDO 将聚合结果返回字符串的行为。

这证明应用在实际 PHP 8.0 运行时通过测试；尚未在用户宝塔的 Linux PHP-FPM 环境验证，部署仍需检查 pdo_sqlite 扩展、SQLite 3.27+ 和站点目录权限。

### 0.3.0 月份锁定验证

111 项真实 HTTP/SQLite/Session 断言通过（测试月为 2026-10）。新增覆盖上月补录、回顾锁定/解锁、锁定后的 CRUD/记录/复制拒绝且数据不变、force 无法绕过、旧月不可解锁、未来月可编辑但不可提前回顾、用户隔离、只读源复制、新增迁移与一致性备份。历史候选测试通过 CLI 在隔离库导入旧月，未增设生产 API 绕过入口。

浏览器验证电脑和 390px 手机视口的回顾开关、锁定提示、计划/记录详情只读、取消标记后恢复入口、更早月份禁用开关。示例截图为 month-review-locked.png 与 month-review-mobile.png。

仓库包含 `tests/api.test.mjs` 和 PHP 测试 fixture，部署包不含测试和本地 PHP 运行时。需要 Node.js 20.11+ 与 PHP 8.0+ 的 PDO SQLite。

```sh
PHP_BIN=/path/to/php node tests/api.test.mjs
node --check public/assets/app.js
```

Windows 默认寻找 `.tools/php/php.exe` 并从所选 PHP_BIN 同目录的 `ext/` 载入 php_pdo_sqlite.dll。若使用其他 Windows PHP，可设置 PHP_BIN。测试在 `tests/tmp/<时间戳>/` 创建独立配置和数据库，在 127.0.0.1:18765 启动服务器，结束后停止，不访问正式 config.php 或 storage。

人工检查：添加不追踪的旅行计划、添加每日项目、打勾/取消、长按填书名、添加链接、新增计划外事项、切换月份、沿用上月、导出图片与表格。真机部署后优先复查手机手势与 HTTPS 会话。
