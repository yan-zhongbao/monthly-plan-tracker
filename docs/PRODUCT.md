# 产品约定

## 已确认的范围

系统名为“月度计划与追踪”。按月使用，时区为 Asia/Shanghai。

八个方面：财务、社交、自我实现、职业、健康、家庭、成长、娱乐。各方面可以留空；月计划页显示八个方面，追踪表按项目顺序连续显示，不插入大类标签；仅保留底部“计划外记录”分隔。图片导出沿用同一规则。

月计划和方面选择器按使用频率排列：成长、健康、家庭、财务、自我实现、社交、娱乐、职业。追踪表仍按项目的 sort_order 连续显示，不按方面重新排序。

添加计划先选所属方面，再选历史项目或输入新名称。历史项目只来自目标月之前、同一用户同一方面仍保存的项目；按最近使用月份、修改时间倒序，排除本月同方面已有的标题。选择仅填名称，不搬入旧备注。没有历史也可以直接新增。编辑已有项目仍可以自由改名称和所属方面。

月计划与追踪项目使用同一条项目数据，以 `tracked` 判断是否进入每日表。国庆旅行、见朋友、看电影、玩游戏三小时等，可以只出现在月计划页并单独打勾。多邻国、得到、跑步、反思等，需要每天提醒的项目进入追踪表。

一个格子只有一个完成状态，不统计同一天多次，不保存公里数。跑步等专业统计由外部系统完成；月表主要帮助观察活动分布。可选目标也是“完成天数”，例如跑步 16 天；单独事项没有每日完成天数目标。

备注是自由文字，适合书名、朋友姓名等信息；链接最多 10 条，只接受 http/https。备注、链接和完成状态独立，可以只记备注而不打勾。

计划外项目 `unplanned=true` 必须进入追踪表、放在底部，不进入原月计划，也不复制到下月。它仍可归属一个方面，方便今后分类分析。

周反思、月回顾可自行添加为普通项目；表格上方的“已完成月回顾总结”是另一个独立的整月锁定标记。不提供文章编辑和自动生成回顾。OpenClaw 负责采集其他平台数据与归档到 Get；网站提供通用接口和手动导出。

## 月份编辑与回顾锁定

- 以服务器配置时区的实际当前月为准，不能通过网页选择月份改变权限。
- 上个月可补录和纠正。上个月和当前月勾选“已完成月回顾总结”后，月计划、追踪格子、备注、计划外事项均只读；取消勾选恢复编辑。
- 再上个月及更早始终只读，不能取消回顾标记解锁。
- 未来月份可编辑，月份到来后才可标记回顾。
- 只读时仍可打开项目/格子查看详情与链接、导出、切换视图；添加和保存入口停用。月计划复制允许读取旧月，目标月必须可编辑且空白。
- 普通“月回顾”项目的打勾不自动锁定；专用开关或 review API 才会锁定，避免普通记录触发意外封存。

## 界面

电脑：利用整个浏览器的可用宽度。通常可看到全月；窄屏电脑会出现横向滚动。左侧项目名固定，周一前增加分隔线，周末轻微底色，今天突出显示。右侧显示完成天数及可选目标。

手机：同一张表，不缩成不可点击的小格子。名称固定，三个日期列约占剩余屏幕，打开当前月时今天在中间；左右滑动查看其余日期。月初/月末受滚动边界限制，不一定能完全居中。“回到今天”也会切回当前月份。

轻点格子立即保存勾选；长按 550ms、右键、Shift+点击或 F2 打开详情。横向/纵向拖动超过 8px 取消长按，防止滑动时误打勾。点击项目名称编辑月计划。

## 状态与修改

未创建记录的空白格子表示尚未标记。取消勾选会保存 `completed=false`，保留备注和链接；页面仍显示空白，但 API 可以区分是否已有记录。

普通点击采用幂等写入，并提交 `revision` 防止同时编辑覆盖。手动操作默认开启 `manual_lock`，OpenClaw 再次自动写入返回 409。详情中可以关闭保护；OpenClaw 也可用 `force=true` 显式覆盖，通常仅在用户明确要求修正时使用。

已有每日记录的项目不能改成非追踪项目，避免隐藏历史；项目月份不可修改。删除项目会连带删除每日记录，删除前页面确认，审计日志保留删除前内容。

## 后续扩展边界

可增加项目排序拖拽、跨月分析、已删除项目恢复、用户管理界面和完整数据库 JSON 导入导出。当前已有配置式多用户和按用户鉴权隔离，但没有注册、用户管理页面及跨用户统计。
