# 90天登录与追踪排序（0.7.1）

登录默认勾选“记住这台设备90天”。有效期从密码登录当天计算，不随访问延长。未勾选时沿用临时会话。每个浏览器保存独立Cookie；清理Cookie、无痕模式、不同浏览器或设备需要重新登录。桌面应用是否与浏览器共享Cookie由浏览器决定，首次可能需要登录一次。

Cookie中保存随机selector与256位随机凭证，数据库remembered_devices仅存凭证SHA-256哈希、密码配置指纹、user_id与到期时间。HTTPS使用Secure，同时HttpOnly、SameSite=Lax。恢复后重新生成会话和CSRF。主动退出撤销当前设备凭证，密码哈希配置改变使旧凭证与会话失效；Bearer API认证不变。保持90天有效并不依赖PHP会话垃圾回收设置。新迁移migrations/common/005自动运行；common目录用于两个数据库兼容的公共SQL，历史专用迁移保持不变，兼容PHP8.0、MySQL5.7及SQLite测试环境。备份包含登录凭证哈希；恢复备份时建议清空remembered_devices使所有设备重新登录。

在月计划中使用每日追踪项目右侧↑↓，移动同一方面的每日项目。一次性事件、独立事项、输出不显示移动按钮。保存后的sort_order同步用于追踪、导出与沿用计划。原项目ID、记录、图标均保持；锁定月份不可排序。

API：PATCH api.php?action=move，Bearer或网页会话+CSRF。JSON：{"id":123,"direction":"up"}，direction为up/down；返回完整月数据。服务器在用户写事务内读取当前顺序，将项目插到同类相邻每日项目前/后，再分配本月唯一顺序并记录项目审计；不存在的/其他用户项目404，锁定月份403，非每日项目400，首尾移动无操作。仅更新顺序及updated_at，不改写每日记录。
