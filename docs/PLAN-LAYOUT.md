# 月计划布局（0.7.3）

电脑端测量月计划卡片容器起点到窗口底部的可用高度（保留24px），按照分类顺序逐列填充。当前列已有卡片且下一卡片的完整高度加间距超过可用高度，则从新列顶部开始。成长、健康等分类不会拆分，DOM阅读与键盘顺序仍为分类顺序。每列宽度按容器宽度计算，最多四列同时可见（最小参考宽度250px）；内容需要更多列时允许横向滚动。单个分类高于一屏时独占一列且保留全部内容，页面允许垂直滚动，不截断卡片。

640px及以下直接取消列容器，所有分类顺序单列展示。切换至月计划、保存项目、加载月份、窗口缩放及字体加载后重新测量。用容器的页面绝对起点计算可用高度，普通页面滚动不会改变分列。卡片DOM节点移动保留原事件处理器，不改变项目、打卡或排序数据。

紧凑行距沿用0.7.2：桌面箭头22px，手机28px，长名称与备注继续换行。升级仅修改JS、CSS、资源与缓存版本，无数据库迁移。planColumns针对用户截图尺寸、准确边界和超高卡片进行独立测试；浏览器工具连接不可用，未宣称实际浏览器截图验证。
