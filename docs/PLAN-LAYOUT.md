# 月计划布局（0.7.2）

桌面使用CSS多列布局（columns:4 250px），按宽度最多四列，较窄屏幕自动减少列数。分类保持成长、健康、家庭、财务、自我实现、社交、娱乐、职业顺序，沿第一列向下阅读，再到下一列。卡片break-inside:avoid，不拆分同一分类；高度由内容决定，不再被同行最高的卡片拉伸。column-fill:balance由浏览器按总内容平衡各列，不设置固定屏幕高度，因此项目多或文字放大时仍可完整滚动查看。

640px及以下取消分列，所有分类按原顺序单列排列。桌面上下箭头22×22px，手机28×28px；条目上下留白由12px缩为5px（手机4px），名称12px/18px行高。长名称与备注仍可换行，不裁剪内容。此样式仅作用于月计划，不改变月度追踪表的行距、打卡操作或已保存顺序。
