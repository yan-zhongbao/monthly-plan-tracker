# 一次性事件与符号（0.5.0）

项目记录方式有三种：仅月计划、每日追踪、一次性事件。一次性事件仍属于原方面，但在月度追踪底部合并为一行。同一天可完成多个不同事项，符号自动换行。桌面悬停显示完整名称和备注，点击符号打开详情；手机点击同样可查看。

已有项目点击名称，在记录方式中切换为一次性事件即可保留原有日期、备注和链接。如果已有多天完成，先取消多余的完成标记。一次性事件每月最多在一个日期完成，改日期需先取消原日期。不推测历史完成日期，也不自动删除已有记录。

点击底部某天的“＋”，选择当天完成的事项。已在其他日期完成的事项显示日期且不可重复完成。详情可以补充书名、朋友名字、链接，也可以取消完成。只读月只能查看。

符号留空时按项目名称匹配：羽毛球🏸、跑步🏃、力量💪、社保圈社、公积金圈公、对账圈对、财务月报圈¥、生日🎂、月计划八瓣花。填写“❀”显示八瓣花。无匹配的日常项目仍用✓，一次性事项用名称首字。自定义符号接口限制为32个UTF-8字节。

目标天数可直接填写；在仅月计划模式填写后会自动变为每日追踪。一次性事件不设置目标天数。深浅交替行保持日期列与名称列同一底色。

## API

原有接口继续可用。`POST/PATCH api.php?action=items` 新增 `once_only`（布尔，默认false）、`symbol`（字符串，默认空）。`once_only=true` 强制 `tracked=true,target=null`。例如：

```json
{"month":"2026-10","title":"社保","category":"财务","once_only":true,"symbol":"社","avoid_duplicate":true}
```

用原有 `PUT records` 写入日期、完成、备注和链接。第二个日期完成同一一次性项目返回409；改为每日追踪后可多次完成。复制月份保留记录方式和符号，清空每日记录。查询仍返回每个项目及独立记录，合并一行属于页面显示方式。

PNG合并一次性事件并附符号名称对照；CSV和JSON保留每个项目及各自的日期，便于迁移。HTML打印使用与页面相同的合并行。

## 升级

先备份数据库和配置，再覆盖程序文件。0.5.0的003迁移只新增 `items.once_only` 和 `items.symbol`，默认值保持旧项目行为。MySQL新增字段迁移支持中断后重试。不要覆盖config.php或storage中的私人数据。回退时可恢复旧代码，两列可保留；旧代码不会显示新的合并方式。生产数据库操作前应保留完整备份。

可用 CLI 工具逐字段核对升级前的 SQL 备份：

```sh
php scripts/verify-upgrade.php storage/backup-before-upgrade.sql 2026-10 社保 公积金 财务月报 对账 家人生日
```

工具只在当前连接创建临时表，不恢复或覆盖正式数据库。按ID核对全部原有记录（含日期、备注、链接、修订号），允许命令列出的当月事项改变一次性显示方式。期间新增内容单独报告，其他项目修改需有从备份原值到现值的完整审计链；记录被修改或项目缺少完整审计链则停止核验，不能直接恢复旧备份。

## 0.5.1 操作调整

记录方式改为三个单选按钮。点击“选择图标”打开常用、运动与健康、学习与创作、生活与事项面板，选择后收起；“恢复自动”清空自定义值。桌面每日行高26px，手机38px；同一天的一次性符号过多时该行自然增高。能否全屏显示取决于项目数量、屏幕高度及浏览器缩放。

未来日期只能查看，不能勾选、取消、填写备注或链接。已有未来记录不删除。API同样返回403和FUTURE_DATE，未来月计划不受限制。

## 0.5.2 符号一致性

月计划中的每日追踪与一次性事件均使用同一个符号显示函数。优先显示数据库的 `items.symbol`；空值代表自动匹配，不会把自动符号写进数据库。用户在图标面板选择后保存项目，才保存自定义值。月计划、月追踪和导出使用同一优先级。

0.5.3在图标面板顶部提供“更多图标”，展开表情、手势、动物植物、饮食、旅行风景、工作工具、爱好庆祝、生活整理、语言国家等分类，共三百多个选项。再次点击收起。图标完全随程序提供，不发送个人数据到外部服务；选择后仍需保存项目才写入数据库。

0.5.4的更多图标新增“运动与拉伸”：瑜伽🧘、体操🤸、滑冰⛸️、滑雪⛷️、单板🏂等，运动图标鼠标悬停提供中文名称，可自由用来代表拉伸或其他项目。已有项目不会因此自动换图标。
