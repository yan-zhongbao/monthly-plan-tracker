# 手机追踪布局（0.6.0）

宽度不超过 640px 时，顶部固定一行站点名称、当前月份和“⋯”。下方直接显示日期表头与追踪项目；表内可上下滚动，日期表头与左侧项目名称保持固定，左右滑动切换日期，默认定位今天及前后日期。每日行仍保留 38px 高度，减少误触。

“⋯”弹出月份与功能菜单，包含 API 说明、保存状态、退出、月份切换、沿用计划、导出、添加项目、月计划切换和月回顾锁定。选择月计划、添加或导出后菜单自动关闭；使用“回到今天的追踪表”回到当前月份和追踪视图。已锁定月份仍可在菜单查看并按原权限取消锁定。

电脑版保留原布局。实现复用原操作控件和事件绑定，在宽度变化时移动到菜单或恢复原位置，不重复控件 ID。未更改项目、完成记录、图标、月份权限或 API 的保存规则。无需数据库迁移。
